# 赫同学工作台 / HE WORKBENCH

> 先导演故事，再导演模型。

高校教师、AIGC 影像教学与实践者的个人工作台。一页装下三件事：做出来的作品、每天在跑的工作流、以及把 AI 从“生成”掰回“导演”的方法。

在线地址：**https://amxi0303-cell.github.io/he-studio/**（Pages 开启后生效）

---

## 技术形态

- 单页、零框架、零构建，直接打开 `index.html` 即可
- 结构：`index.html` + `assets/site.css` + `assets/site.js`
- 字体走自托管镜像，加载失败时回落 PingFang / 宋体 / 系统字体
- 无统计脚本、无 cookie、无第三方追踪
- 响应式：≤1000px 两列，≤720px 单列，导航自动收起

## 怎么改

1. **改文案**：按区块注释定位，如 `<!-- ===== 视图：作品 ===== -->`；`.lede`、`.sec-note` 是主要文案位。
2. **换作品**：复制 `<article class="work">` 整块，改标题、日期、标签、仓库链接。
3. **换工作流**：`data-cat` 决定筛选归类（`teach` / `story` / `art` / `sound` / `tech`），筛选按钮在 `.chips` 里，数量文案需同步。
4. **改联系方式**：全站搜索 `amxi0303-cell`，导航、合作区、页脚三处一起换。
5. **首屏数字**：`data-gh` 开头的由 GitHub 公开接口自动填充；`85`、`21`、`13` 是手写口径，改了事实就要改数字。

## 数据与隐私

- 仓库、星标、复刻、关注数在页面打开时从 `api.github.com` 实时读取；接口不可用时显示“—”，不做估算，不写死成漂亮数字。
- 站点不采集任何访问者信息。

## 开启 GitHub Pages（三步）

1. 进入 **Settings → Pages**
2. Source 选 **Deploy from a branch**，Branch 选 **main**，目录选 **/(root)**
3. Save，等 1–2 分钟访问 `https://amxi0303-cell.github.io/he-studio/`
